# 配置中心

配置中心页汇聚了软件全局配置的统一入口，涵盖语言切换、IO引脚配置、软件与固件升级、初始姿态查看及机械臂状态检测等核心管理功能，助您高效完成设备与系统的全面调校。

## 界面介绍

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-1.png" />

| 序号 | **功能介绍** |
| ---- | ------------ |
| 1    | 软件语言模块：可设置软件当前语言 |
| 2    | 引脚配置模块：可配置底座与末端工具的IO接口 |
| 3    | 检查更新模块：可对软件及固件进行下载与升级 |
| 4    | 初始姿态模块：可查看与切换初始姿态和打包姿态 |
| 5    | 测试模块：可检测通讯连接、固件及舵机状态 |
| 6    | 模块内容显示区域：展示当前选中模块的操作界面 |

## 软件语言

> 以下是对软件语言设置功能的介绍，用于切换软件界面的显示语言（中文/English）

点击 `软件语言` 图标按钮，将进入语言设置页面，语言选择支持`中文`和`English`。

选择对应语言之后，点击 `保存` 按钮，会出现二次确认提示信息弹窗。点击`确认`按钮，即可成功设置语言。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-3.png" />

当语言切换完成后，软件将根据切换的语言进行展示。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-4.png" />

## 引脚配置

> 以下是对引脚配置功能的介绍，用于配置和监控底座及末端工具的数字 IO 引脚

点击 `引脚配置` 图标按钮，本模块用于配置和监控机械臂底座及末端工具的数字IO接口。通过物理仿真视图与逻辑配置表格的结合，用户可以定义引脚的信号方向(输入/输出)及默认电平状态（高电平/低电平）。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-5.png" />

**默认电平**

可设置引脚默认电平：输出模式下发送物理电平；输入模式下通过上/下拉电阻配置电平状态（用于无外部接入时的测试）。系统默认设置下，输入引脚配置为内部上拉（高电平），输出引脚初始输出低电平。

**引脚配置**

可配置各个IO口的输入输出(除工具IO的IO1、IO2固定为输入引脚，IO3、IO4固定为输出引脚)

底座引脚口1-5号默认选中输入;底座引脚口6-10号默认选中输出。

单条引脚的配置（输入输出模式或默认电平）修改后，该条引脚配置实时同步至[调试面板](./5.3.4-debugPlane.md)的对应引脚配置项

> 注意：引脚配置页面专用于初始化默认电平，相关I/O口的修改会实时同步至调试面板。调试面板显示的为引脚当前的实际电平状态。

> 以底部IO引脚号1为例操作

引脚配置由输入修改为输出。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-6.png" />

修改成功后将会返回【指令下发成功】。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-7.png" />

默认电平由高电平修改为低电平，修改成功后将会返回【指令下发成功】，且默认状态栏高电平标志消失。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-8.png" />

修改完成后，前往调试面板页查看修改项，状态已完成同步。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-9.png" />

## 检查更新

> 以下是对检查更新功能的介绍，用于检测并升级 myStudio Pro 软件、屏幕驱动和运动固件的版本

点击 `检查更新` 图标按钮，将进入检查更新状态页面，该页面可用对软件驱动（myStudio Pro、屏幕驱动、运动固件）进行下载、删除、升级操作。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-10.png" />

当软件/固件存在最新版本且未进行升级操作时，`检查更新`图标旁会有红色数字1显示，此时代表存在新版本未更新，您可进入该页面查看具体的升级内容。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-11.png" />

在该页面可以开启软件或固件的自动下载功能，顾名思义自动下载会将需要最新软件或固件版本后台静默下载。

**注意：** 开启或关闭自动下载，都需要重启软件才生效

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-12.png" />

若您对软/固件升级存在疑惑，您可将鼠标移至该区域，并点击对应的升级帮助链接将使用默认的浏览器打开文档链接。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-n-1.png" />

### 新版本弹窗提醒

> 以下是myStudio Pro软件检测到新版本功能的介绍，有新版本时进入主页会弹出升级信息弹窗

存在新版本的软件/固件时，进入主页面会弹出升级信息弹窗，通过弹窗可查看包含的新版本内容。

当新版本弹窗展示时，若点击`稍后更新`或关闭弹窗则不前往检测更新页，反之点击`前往更新`则跳转至检查更新页，仍需手动更新。

## 测试模块

> 以下是对测试模块功能的介绍，用于检测通讯连接、固件版本和舵机状态，支持保存测试日志

点击 `测试模块` 图标按钮，将进入测试页面。

`测试` 页面：主要测试机械臂的通讯连接、固件版本、舵机等状态。

通讯状态：检测软件与机械臂是否正常通信

固件版本：检测机械臂的屏幕固件和运动固件是否为最新版本

舵机状态：检测当前舵机是否正常

测试完成每一测试项后会展示本次测试的结果是否通过，绿色代表正常，反之不正常，可将测试结果保存到本地日志文件进行具体测试内容查看。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-44.png" />

点击 `开始检测` 按钮，即可开始进行测试。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-45.png" />

测试完成后，点击 `保存测试日志`  按钮进行测试日志保存。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-46.png" />

首先会展示文件保存路径弹窗，可选择日志文件保存的路径。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-47.png" />

点击保存按钮后，将在该路径下保存默认名【test.log】的日志文件，文件名支持修改。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/configuration-48.png" />
