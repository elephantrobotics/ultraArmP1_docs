## 2 积木编程工作台

> 以下是对积木编程工作台的简单介绍，含积木块仓库、编程区，可在该工作台进行积木编程

每个积木块的功能说明，可查看[积木块介绍章节](../5.5-blocks.md)

工作台为可视化编程区域，包括工具箱、工作区、校准、放大、缩小和垃圾桶功能。

`工具箱`主要为软件预设提供的积木块接口，可通过鼠标左键`点击`选择，`长按`拖动至编程区，可以通过拼接积木块的方式进行可视化编程，降低编程难度。

`编程区`您可以理解为一个公共的收纳区，任何存在的积木块都会以特定的方式转为可执行代码并作用于机械臂。进行积木编程时建议您遵循`拼接`的规则，避免出现执行混乱的问题。

同时工作台右下角还支持对编程视角的放大、缩小和校准功能。顾名思义放大是将编程区视角放大，反之则为缩小，校准则是将视角恢复至默认。

若您想对某个积木块进行快捷操作如复制、删除、禁用等操作。可以选择需要操作的积木块同时点击鼠标右键，将展示操作菜单。删除后的积木块想继续使用可以点击工作台右下角的`垃圾桶`图标，点击后会展示本次编程区删除过的代码，若您想继续使用重新拖动至编程区即可。

接下来以一个简单的数学算数题为例，带您简单熟悉以上介绍的功能。

首先，点击左侧工具栏的`基础编程`，点击`运算`分类，将展示该类别下可用的积木块。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-39.png" />

然后，将两个积木块均拖动至编程区，并进行拼接，注：部分积木块存在参数预留功能可通过积木块与积木块间的联合实现拼接的效果。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-40.png" />

完成拼接后，要想查看编程的效果，还需要将积木代码运行。点击工作台右上角处的`运行面板`，打开运行面板后点击`运行全部`按钮即可进行代码运行。

可以观察到，积木块转为了实际的运行代码，并展示到了日志面板中，为了您能更好的看懂运行日志，建议您掌握简单的Python语法。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-41.png" />

> 有输出值积木块一般前端或末端会有凸口，该类型积木块可与凹口积木块进行拼接。无输出值积木块则前末端直接闭合。

若您想知道某些积木块的执行结果，您还需要使用输出积木块。以上述例子进行简单介绍。选择`文本`分类，将`输出`积木块拖出并与要看输出结果的代码进行拼接。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-42.png" />

此时再将编程区代码运行，并查看日志面板。可以观察到运行结果也一并展示。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-43.png" />

若您想再编程相同的积木块，可以使用`复制`功能，首先选中积木块，可鼠标右键展示操作菜单选择复制或使用键盘`Ctrl + C`与`Ctrl + V`方式实现。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-44.png" />

点击`复制`项后，将对该积木块进行复制操作。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-45.png" />

若您想将某一积木块删除，可用使用`删除`功能，首先选中积木块，可鼠标右键展示操作菜单选择删除或使用键盘`Backspace`与`Delete`方式实现。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-46.png" />

删除后的积木块均进入垃圾桶，需再次使用时可重新拖拽至编程区。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-47.png" />

通过一个简单的积木编程介绍，您已经大致掌握积木编程工作台的功能。若想编程更复杂的代码，需要您花更多的时间探索！

## 4 路点

> 以下是对路点功能的介绍，用于录入多个路点数据（关节+坐标），让机械臂按顺序自动到达各预设位置。

功能描述：通过`录入多个路点数据（机械臂的关节和坐标）`信息，快速控制机械臂到达每个路点的位置。打开路点列表页面，长按末端按钮，放松机械臂，手动调整机械臂姿态，点击新增点位，可以添加一条路点数据。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-1.png" />

| 序号 | 功能介绍                                                         |
| ------ | -------------------------------------------------------- |
| 1    | 点击“导入”按钮，可以把之前保存好的路点信息json文件导入进来。 |
| 2    | 点击“保存”按钮，可以把路点信息全部导出合成一个json文件。     |
| 3    | 点击“删除”按钮，可以把当前路点列表中所有选中的路点进行删除操作。   |
| 4    | 点击“复制”按钮，可以把当前所有选中的路点进行坐标信息复制操作。 |
| 5    | 点击“重命名”按钮，可以把当前所有选中的路点进行路点名重命名操作。   |
| 6    | 点击“覆盖当前点”按钮，可以把当前机械臂坐标信息快速覆盖所有选中路点的坐标信息。 |
| 7    | 列表数据勾选列，功能3-6以该功能为前提。                      |
| 8    | 点击“运行”按钮，机械臂会运动到当前所录的路点位置             |
| 9    | 点击“新增点位”按钮，会录入当前机械臂的坐标信息 |
| 10   | 点击“生成代码”按钮会快速生成路点积木块到blockly程序编码区     |

在`积木编程`中选择路点积木块，加入到程序编码区。或者使用路点列表中的`生成代码`按钮，会在工作区最后一个积木块上拼接生成的路点积木块。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-2.png" />

路点积木块关联路点列表中的数据，选择路点列表中任意路点进行关联。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-3.png" />

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-4.png" />

路点积木块新增点位信息。选择新增点位，点击编辑图标打开新增路点弹框，这时会默认自定义路点名字，通过+或者-进行调整好路点信息，点击保存路点按钮，即可添加路点数据。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-5.png" />

| 1    | 选择路点，点击编辑图标后，会打开路点编辑弹框                 |
| 2    | 输入路点名称                                                 |
| 3    | 显示机械臂的关节和坐标数据，通过按钮左边(-)和右边(+)按钮进行调整路点数据 |

## 5 轨迹

> 以下是对轨迹功能的介绍，通过手动拖拽机械臂录制运动轨迹，随后可选择并复现该轨迹

功能描述：通过`录制轨迹数据（机械臂的关节）`信息，快速控制机械臂到达每一个轨迹点位置。打开轨迹列表页面，点击录制轨迹按钮，机械臂各关节将放松，按下末端按钮并手动拖动机械臂录制轨迹，点击停止录制等待轨迹保存，保存完成即轨迹录制完成。（关于文件功能相关操作，[请点这里](./5.3.3-blockly.md#11-文件管理)）。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-6.png" />

| 序号 | 说明                                                         |
| ---- | ------------------------------------------------------------ |
| 1    | 先选择需要删除的轨迹，至少勾选一条数据按钮可用，点击删除即可将所有勾选的轨迹删除。 |
| 2    | 列表数据勾选列，功能1以该功能为前提。     |
| 3    | 点击“复现”按钮，可以对该轨迹进行复现操作。   |
| 4    | 点击“保存”按钮，可以把当前轨迹拷贝至测试文件工作区。 |

## 6 运行程序

> 以下是对运行程序功能的介绍，可通过单步执行来运行单个积木块，也可通过运行面板来运行工作台全部积木块文件

介绍如何通过`运行面板`来调试积木块代码，实现程序的 `暂停`、`恢复`、**`单步执行`**、`停止`。

编辑一段控制 机械臂 `关节1` 运动的程序。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-29.png" />

点击`运行面板`按钮，当运行面板弹出后，点击`运行全部`，马上点击 `暂停`按钮，程序会在执行完第一条指令`mc.set_angle(1,0,20)` 后暂停。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-30.png" />

程序已暂停。出现下一条要执行的指令`time.sleep(3)`

此时：

- 如果点击`恢复`按钮，程序将会自动往下执行；
- 如果点击`单步执行`按钮，程序会执行`time.sleep(3)`指令，再次点击`单步执行`时,程序会执行下一条指令，即`mc.set_angle(1,-90,20)`；
- 如果点击`停止`按钮，程序会被终止；

至于接下来如何操作，由您自己决定吧！

所谓的单步执行，是指：单积木块执行。当工作区存在大量积木块时，我只想执行其中的一个积木块，看看是什么效果。这个时候就可以用到 单步执行。

> **单步执行** 按钮 默认处于禁用状态，是不可点击的

**第一步：** 拖动几个设置关节积木块进入工作区

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-26.png" />

**第二步：** 选中 `设置关节` 积木块，观察到 **单步执行** 按钮已被解锁（颜色变为了深色）

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-27.png" />

**第三步：** 点击 **单步执行** 按钮，会自动打开运行面板，并开始执行代码。同时，观察机械臂运动变化。(单步执行设置关节1为30°)

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-28.png" />

## 9 门型移动抓取案例

> 以下是对门型移动抓取案例的介绍，请确保机械臂末端已装配吸泵工具

阅读该小节前请确保您对已掌握路点、程序运行、文件管理功能，请确保机械臂工作区无障碍物，保证机械臂的正常运动。

首先需要将抓取物件放置至工作范围内，待抓取物件放置平稳后，此时需要将物件的点位信息进行记录，可以使用`自由移动`和`路点`功能。

1. 开启`自由移动`模式。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/case-1.png" />

2. 按住`白色磨砂`按钮，将机械臂移动至抓取物件正上方位置，位置到达后放开松开按钮并打开点击`路点轨迹`面板，点击`新增点位`将该点位数据记录（点位1）。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/case-2.png" />

3. 物件正上方的点位记录完成后，需要记录吸泵需抓取的点位，同样的按下`白色磨砂`按钮将机械臂移动至吸泵工具可抓取物件的位置，位置到达后松开按钮并打开点击`路点轨迹`面板，点击`新增点位`将该点位数据记录（点位2）。
> 该位置主要是为了吸泵可以成功抓取物件

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/case-3.png" />

4. 完成上述步骤后，此时建议您将点位2复制为一个过度点（点位3）。

5. 现在需要定义一个物件释放点正上方，您可以通过自由移动或快速移动将机械臂调整至对应的点位，该点位建议只运动关节1，完成移动后同样的将该点位记录（点位4）。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/case-5.png" />

6. 完成点位4记录后，最后就需要定义实际的物件释放点，建议为点位4的正下方（点位5）。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/case-7.png" />

8. 最后，点击右上角回零按钮或使用积木块将机械臂运动至初始位置，并将该位置记录（点位7）。

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/case-8.png" />

完成本次案例的所有点位信息记录后，此时就需要使用到`末端工具`类别中的吸泵控制和`运动控制`类别路点积木块，若您对路点功能不熟悉，建议您先仔细阅读[路点](./5.3.3-blockly.md#4-路点)介绍。
