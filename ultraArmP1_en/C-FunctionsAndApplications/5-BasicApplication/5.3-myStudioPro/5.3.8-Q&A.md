# Q&A

**Q1: myStudio Pro software is starting very slowly?**

A: During the software startup, necessary configurations need to be loaded. Once the loading is complete, the main interface will automatically open. The entire process may take some time. Please be patient and wait. If there is no response for a long time, please contact the after-sales technical support.

**Q2: When update check page and attempting to download, it shows that the download failed and the file couldn't be downloaded properly?**

A: Before using the "Check for Updates" feature, make sure your device is connected to the internet. Without an internet connection, the software driver cannot be downloaded properly. Additionally, the network quality will also affect the function usage. A slower network connection may result in the failure of driver download. To ensure the function operates normally, please check the network status in advance.

**Q3: Did the firmware upgrade fail during the process?**

A: Please ensure that the robotic arm is properly powered on during the upgrade process. Then try to upgrade again. If all upgrades fail, please contact the after-sales service for a solution.
