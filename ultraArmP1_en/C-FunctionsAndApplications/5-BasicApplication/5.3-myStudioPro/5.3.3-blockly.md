# Block Programming

The building block programming page integrates block-based drag-and-drop programming and quick access to core functions, covering the entire process of program editing, generation and invocation of waypoints and trajectories, running and debugging, joint control, and file management. It provides a one-stop solution for development and debugging needs.

You can click the `Block Programming` icon, or click the Create File button to enter the Block Programming page.

> Of course, you can also click the `Open File` button, which will automatically navigate to the Block Programming page and load the content of the file you have saved, including the workspace, waypoints, and trajectory files (for how to save the workspace, [please click here](./5.3.3-blockly.md#9-gate-style-pick-and-place-case))
>
> Clicking the Block Programming icon or the Create File button to enter the Block Programming page is equivalent to creating a new workspace.

## 2 Block Programming Workbench

> The following is a brief introduction to the Block Programming workbench, including the block repository and programming area, where you can perform block programming

The function description of each building block can be found in the [Building Block Introduction Section](../5.5-blocks.md)

The workbench is a visual programming area, including the toolbox, workspace, calibration, zoom in, zoom out, and trash can functions.

### 2.1 Toolbox

The software provides a pre-set interface of building blocks, which can be selected by clicking with the left mouse button. Then, drag it to the programming area by holding down the mouse button. Visual programming can be achieved by stacking the building blocks up and down, thereby reducing the difficulty of programming.

### 2.2 Workspace

You can think of it as a common storage area where any existing building blocks will be transformed into executable code and applied to the robotic arm in a specific way. When programming with building blocks, it is recommended that you follow the "assembly" rules to avoid confusion in execution. Select the building blocks you want to operate on and click the right mouse button at the same time. This will display the building block operation menu, including operations such as copying, deleting, and disabling.

### 2.3 Calibration

Adjust the size of the programming perspective and restore the programming area perspective to its default state.

### 2.4 Zoom in

Adjust the size of the programming perspective and enlarge the perspective of the programming area.

### 2.4 Zoom out

Adjust the size of the programming perspective and reduce the size of the programming area perspective.

### 2.5 Trash can

After deleting the building blocks, if you want to reuse them, you can click the Trash Can icon at the bottom right of the workbench. After clicking, the deleted code in this programming area will be displayed. If you want to continue using them, simply drag them back into the programming area.

Next, a simple arithmetic example is used to help you get familiar with the functions introduced above.

First, click `Basic Programming` in the left toolbar, then click the `Math` category to display the available blocks in that category.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-39.png" />

Then drag both blocks to the programming area and assemble them. Note: Some blocks have parameter slots and can be assembled by combining blocks with matching connectors.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-40.png" />

After assembly, to see the programming result, you still need to run the block code. Click `Run Panel` in the upper-right corner of the workbench. After the run panel opens, click the `Run All` button to run the code.

You can observe that the blocks are converted into actual running code and displayed in the log panel. To better understand the run logs, it is recommended that you learn basic Python syntax.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-41.png" />

> Blocks with output values usually have a protruding connector at the front or end and can be assembled with blocks that have a matching recessed connector. Blocks without output values are closed at both ends.

If you want to know the execution result of certain blocks, you also need to use an output block. Taking the example above, select the `Text` category, drag out the `Print` block, and assemble it with the code whose output you want to see.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-42.png" />

Then run the programming area code again and check the log panel. You can observe that the run result is also displayed.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-43.png" />

If you want to program the same blocks again, you can use the `Duplicate` function. First select the block, then right-click to show the operation menu and choose Copy, or use `Ctrl + C` and `Ctrl + V` on the keyboard.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-44.png" />

After clicking `Duplicate`, the block will be copied.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-45.png" />

If you want to delete a block, you can use the `Delete` function. First select the block, then right-click to show the operation menu and choose Delete, or use `Backspace` or `Delete` on the keyboard.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-46.png" />

Deleted blocks all go into the trash can. Drag them back to the programming area when you need them again.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-47.png" />

If you want a certain building block to exist in the programming area but want the actual running logic of that block to be skipped during runtime, you can use the `Disable` function. The building block menu offers the `Disable` and `Enable` options. Select the building block you want to operate on by right-clicking with your mouse.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-51.png" />

The disabled block styles will display a pattern similar to a cross grid. Similarly, the disabled blocks can also be enabled.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-52.png" />

Through this simple block programming introduction, you have roughly mastered the workbench functions. To write more complex code, you will need more time to explore!

## 5 Trajectory

> The following introduces the trajectory function: manually drag the robotic arm to record a motion trajectory, then select and play it back

Function description: By recording trajectory data (robotic arm joints), you can quickly control the robotic arm to reach each trajectory point. Open the trajectory list page, click Record Trajectory, the joints of the robotic arm will relax, press the end-effector button and manually drag the robotic arm to record the trajectory, click Stop Recording and wait for the trajectory to be saved. Once saved, trajectory recording is complete. (For file-related operations, [please click here](./5.3.3-blockly.md#3-file-management)).

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-6.png" />

| Number | Description |
| ---- | ------------------------------------------------------------ |
| 1 | Delete button：First select the trajectories to delete. At least one item must be checked for the button to be available. Click Delete to delete all checked trajectories. |
| 2 | List data selection column: Prerequisite for function 1. |
| 3 | Repetition button：play back the trajectory. |
| 4 | Save button：copy the current trajectory to the test file workspace. |
| 5 | Record Trajectory button：The robotic arm will ask for secondary confirmation before recording. After confirmation, recording starts (maximum 120s; recording stops automatically when exceeded). |

Click the `Waypoint & Trajectory` button to open the function panel. Switch to the trajectory list section. Click the `Record Trajectory` button at the bottom right of the panel. A confirmation pop-up window for enabling the free movement mode will appear.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-10.png" />

Click the `Confirm` button, and the robotic arm will automatically relax and enter the trajectory recording stage. At this time, you can freely drag the robotic arm to record the trajectory. The button at the bottom right of the panel will change to `Stop recording` and the duration of this recording will be updated in real time.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-11.png" />

When the `Stop recording` button is clicked when no more trajectory is being recorded, the recording stops and the robotic arm is properly locked. The trajectory recording is completed (the maximum recording time is 120 seconds; it will automatically stop after the time limit is reached).

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-12.png" />

After recording, the trajectory list will add the corresponding trajectory data. You can replay the recorded trajectory by clicking the `Repetition` button. When you click the `Repetition` button, the robotic arm will start the trajectory replay, and a message indicating the start will be displayed on the page.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-13.png" />

When the trajectory reproduction is completed, the robotic arm stops moving and the page will display a message indicating the end.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-14.png" />

**Note:** The trajectory list only stores one trajectory data. The newly recorded trajectory will overwrite the previous data. You can save this trajectory to the file management list for easy reuse of the recorded trajectories. Just click the `Save` button.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-15.png" />

In `Block Programming`, select the trajectory block and add it to the program programming area. The trajectory data in the drop-down menu of the building blocks is derived from the current trajectory list. It is not possible to manually input the trajectory path.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-7.png" />

In the workspace, click the drop-down menu of the trajectory block to select data from the current trajectory list page.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-8.png" />

After selection, open the Run Panel and click Run All to play back the trajectory via block execution.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/wp-9.png" />

After the program finishes, trajectory playback is complete. You can also combine other blocks for more complex programming.

## 6 Run Program

> The following introduces the run program function. You can run a single block via one-step execution, or run all blocks in the workbench via the run panel

One-step execution means: execute a single block. When there are many blocks in the workspace and you only want to execute one of them to see the effect, you can use one-step execution.

`The One-step` button is initially in an disabled state and cannot be clicked. This function can only be used when a single building block has been selected.

**Step 1:** Drag several Set Joint blocks into the workspace.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-26.png" />

**Step 2:** Select the `Set Joint` block. You will observe that the **One-step** button has been unlocked (its color becomes darker).

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-27.png" />

**Step 3:** Click the `One-step` button. The run panel opens automatically and code execution starts. Observe the robotic arm motion changes. (One-step sets joint 1 to 30°)

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-28.png" />

This section introduces how to debug block code through the `Run Panel`, including program `Pause`, `Resume`, `One-step`, and `Stop`.

Edit a program that controls the motion of robotic arm `Joint 1`.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-29.png" />

Click the `Run Panel` button. When the run panel appears, click `Run All`, then immediately click the `Pause` button. The program will pause after executing the first instruction `mc.set_angle(1,0,20)`.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/blockly-30.png" />

The program is paused. The next instruction to be executed, `time.sleep(3)`, appears.

At this point:

- If you click the `Resume` button, the program will continue automatically;
- If you click the `One-step` button, the program will execute the `time.sleep(3)` instruction. Click `One-step` again to execute the next instruction, namely `mc.set_angle(1,-90,20)`;
- If you click the `Stop` button, the program will be terminated;

What to do next is up to you!

## 9 Gate-Style Pick-and-Place Case

> The following introduces the gate-style pick-and-place case. Please ensure that a suction pump tool is installed at the end of the robotic arm

Before reading this section, make sure you have already mastered the waypoint, program running, and file management functions. Also ensure there are no obstacles in the robotic arm workspace so that the arm can move normally.

First, place the object to be picked within the workspace. After the object is placed steadily, record its point information. You can use the `Freemove` and `Waypoint` functions.

1. Enable `Freemove` mode.

Likewise, press the `white frosted` button and move the robotic arm to a position where the suction pump tool can pick the object. After reaching the position, release the button, open the `Waypoints & Trajectory` panel, and click `Add a new point` to record this point data (Point 2-Grab point).

Likewise, Point 5 is the object release point. Assemble a suction pump control block with it and set the status to Open. When this code is executed, the suction pump will release the object.
