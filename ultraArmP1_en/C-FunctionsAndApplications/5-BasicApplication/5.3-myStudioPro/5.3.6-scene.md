#### Top Toolbar

It provides five function buttons: Back, New, Case Library, Quick Movement, and Free Movement. The New button is used to enter the workbench to create patterns; the Case Library contains pre-set G-code files; Quick Movement supports jog debugging and special point settings; and Free Movement allows you to manually drag the robotic arm to the target position.

**Back:** Click the button to return to the main page of the scene application.

**New:** After clicking the button, you can enter the Write and Draw workbench to create and edit a new project.

**Case Library:** The drop-down menu enables you to browse and select the built-in preset machinable G-code files, and quickly load their machining trajectories into the center preview area.

> The built-in G-code in the case library is for vector drawing. To ensure the case runs properly, adjust the distance from the pen tipto the lower edge of the pen clamp to 5 cm. If the distance isincorrect, the pen may fail to touch, hover above the surface, or presstoo deep.

After a case is loaded, the run panel is displayed, and you can run the case G-code.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-n-1.png" />

**Quick Movement:** Clicking opens the Quick Movement page, which supports setting the work origin, trajectory starting point, precise point debugging, and real-time coordinate reading.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-4.png" />

**Free Movement:** When clicked, a message box will pop up. After confirming, the robotic arm can be manually dragged and moved to the initial position, simplifying the debugging process. For the detailed control logic, see the [Free Movement](./5.3.3-blockly.md#8-free-movement) feature description.

**Main View:** After clicking the button, the 3D preview area is restored to its default initial perspective. The main view of this page defaults to a top-down view.

**Rotate Left:** Supports single-click and long-press. Click to rotate 15°, and long-press to rotate continuously to the left at 30°/s until you release the button.

#### 3D Trajectory Preview Area

Displays the machining trajectory of the currently selected G-code file in 3D. The sector boundary represents the machinable range of the robotic arm. The lower-right corner provides zoom controls for fine view adjustment.

You can drag with the mouse to pan the view, and use the scroll wheel to set the zoom center.

**Calibration:** Click the `Calibration` button to restore the view to the default main perspective and restore the zoom ratio to the default value (10 mm/grid).

**Zoom In:** Click the `Zoom In` button once to enlarge the view by one level. The scale switches to a smaller value according to the preset sequence (for example, from 10 mm/grid to 5 mm/grid). Continuous clicks are supported to gradually zoom in to the minimum scale of 1 mm/grid. Once the minimum scale is reached, clicking the button has no effect.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-12.png" />

**Zoom Out:** Click the `Zoom Out` button once to reduce the view by one level. The scale switches to a larger value according to the preset sequence (for example, from 10 mm/grid to 50 mm/grid). Continuous clicks are supported to gradually zoom out to the maximum scale of 100 mm/grid. Once the maximum scale is reached, clicking the button has no effect.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-13.png" />

**Scale:** The current scale is displayed in the lower-right corner, in the format `10mm`, indicating the actual length represented by each small grid cell. The supported scale sequence is 100 mm, 50 mm, 10 mm, 5 mm, and 1 mm.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-14.png" />

#### Run Panel

When the page is loaded, no G-code file is selected and the run panel is hidden. After a G-code file is selected, the run panel for that file is displayed. The panel shows the estimated duration, running time, and current status of the robotic arm, and supports run, pause, stop, and resume controls for machining tasks.

**Long press to work origin:** After long pressing the button, the robotic arm moves to the preset work origin. Once homing is complete, the Run, Pause, and Stop buttons are displayed.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-25.png" />

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-26.png" />

**Run:** After clicking the Run button, the robotic arm starts running the machining file. The running time starts counting, the current status changes to Running, the Run button becomes disabled, and the Pause and Stop buttons become enabled.

> When the robotic arm is running, some page functions are disabled to prevent unexpected operations, such as page navigation, file switching, import, and export. These functions are restored when the file finishes running or is stopped.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-27.png" />

**Pause:** After clicking the Pause button, the robotic arm pauses. The current status of the panel changes to Paused, the Run button becomes the Resume button, the Pause button becomes disabled, and the Resume and Stop buttons become enabled.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-28.png" />

**Resume:** After clicking the Resume button, the robotic arm resumes motion.

**Stop:** After clicking the Stop button, the software stops issuing commands. The current status is Stopped. Except for the Run button, which is enabled, the Pause and Stop buttons are disabled. The robotic arm stops after completing the commands already sent, and the current status of the run panel becomes Pending.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-29.png" />

**Insert into Blockly:** After clicking the Insert into Blockly button, you are redirected to the Blockly Programming Workbench, where you can achieve batch execution through block-based programming. For details about this page, see the [Blockly Programming Feature Description](./5.3.3-blockly.md).

Cut, copy, paste, and delete also support shortcut keys: Ctrl+X, Ctrl+C, Ctrl+V, and Backspace/Delete, for faster editing.

**Select Tool:** Used to select graphic objects on the canvas. Supports single-click selection of one object, or dragging the mouse to box-select multiple objects. After selection, the object color changes to blue, and you can move, scale, and rotate it. Hold Shift to add more objects to the selection.

#### Right Property Panel

As the core area for graphic property configuration and machining preparation, it switches between the Edit and Process modules via tabs. The Edit module supports layer management (rename, level adjustment, and delete) and transformation property adjustment for graphic objects (coordinates, size, text, and image processing mode). The Process module supports selecting graphic objects and creating tool paths, then continues into machining parameter configuration and G-code generation, enabling a seamless flow from design to machining.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-85.png" />

**Layer List:** Displays the layer list of all graphic objects on the current canvas. Each layer item shows the object name. Supports single or multiple selection. When selected, the corresponding object on the canvas turns blue, and the transformation area below synchronously shows the object property parameters (only for single selection). Each list item has a show/hide button on the left to show or hide the layer.

- When no layer is selected, all four management buttons in the layer list are disabled.
- When one layer is selected (image type), all four buttons are enabled, the transformation area and processing mode are shown, and you can modify object properties (coordinates, size, rotation/mirroring, and image processing mode).
- When one layer is selected (graphic type), all four buttons are enabled, the transformation area is shown, and you can modify object properties (coordinates, size, and rotation/mirroring).
- When one layer is selected (text type), all four buttons are enabled, the transformation area and text processing are shown, and you can modify object properties (coordinates, size, rotation/mirroring, and text processing).
- When two or more layers are selected, only the "Delete" button is enabled, and the other three buttons are disabled.

**Rename:** After selecting a single layer, click the button to rename the layer.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-86.png" />

**Move Up:** After selecting a single layer, click this button to move the current layer one level up in the list so it can cover the layer below. Continuous clicks are supported until it reaches the top.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-87.png" />

**Move Down:** After selecting a single layer, click this button to move the current layer one level down in the list so it is covered by the layer above. Continuous clicks are supported until it reaches the bottom.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-88.png" />

**Delete:** After selecting a layer, click this button to delete the currently selected layer and its corresponding graphic object.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-89.png" />

**Transformation Area:** Displays the transformation property parameters of the currently selected graphic object and supports precise adjustment of position, size, and rotation angle by entering values. This area is shown only when a single layer object is selected.

- Move: Displays the X and Y coordinates (in mm) of the currently selected graphic object. You can enter values to precisely adjust the object position on the canvas. The coordinate origin is the canvas center (0, 0). Positive and negative values are supported, and the input range is -400 to 400.
- Size: Displays the width (W) and height (H) (in mm) of the currently selected graphic object. You can enter values to precisely adjust the object size. Aspect ratio locking is supported (controlled by an external button). When enabled, modifying either value changes the other proportionally.
- Rotate: Displays the rotation angle (in degrees) of the currently selected graphic object. You can enter a value to rotate the object. The input range is 0 to 360. You can also drag the rotation control point on the canvas, and the value updates in real time.
- Horizontal Mirror: After clicking, the currently selected graphic object is flipped horizontally along the vertical axis (left-right mirror). The flip center is the geometric center of the object. The center point coordinates remain unchanged, and the graphic content is swapped left and right. Continuous clicks are supported (each click flips once). This operation supports undo (Ctrl+Z) to restore the pre-mirror state.
- Vertical Mirror: After clicking, the currently selected graphic object is flipped vertically along the horizontal axis (up-down mirror). The flip center is the geometric center of the object. The center point coordinates remain unchanged, and the graphic content is swapped up and down. Continuous clicks are supported. This operation supports undo (Ctrl+Z) to restore.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-90.png" />

**Processing Mode:** The processing mode area is displayed only when an image object alone is selected. Four image processing modes are supported, and the displayed fields vary by mode.

Black and White: Available when an image object is selected. After clicking, the image is converted to a black-and-white binary image (only black and white colors are retained), suitable for generating machining trajectories with clear contrast and distinct outlines.

- Invert: Switch button to reverse black and white colors.
- Threshold: Supports input box or slider input to set the grayscale threshold (0-255). Pixels above the threshold become white, and those below become black.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-91.png" />

Grayscale: Converts the image into a grayscale image, suitable for engraving effects that need fine light-and-dark transitions.

- Contrast: Supports input box or slider input to adjust image contrast. A larger value means stronger contrast. The input range is 0 to 100.
- Brightness: Supports input box or slider input to adjust overall image brightness. The input range is 0 to 100.
- White Clip: Supports input box or slider input to set the highlight cutoff value. Pixels above this value are processed as white to avoid overexposure. The input range is 0 to 255.
- Algorithm: Click the drop-down box to select an image processing algorithm (such as Atkinson or Floyd-Steinberg) to optimize the visual effect of grayscale conversion.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/scene-92.png" />
