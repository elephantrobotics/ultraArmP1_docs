## 2 Switching of Connection Methods 

> The following is an explanation of the software's function of switching between corresponding pages for wired and wireless connections of the robotic arm.

When the software is launched, it defaults to the `wired` connection mode. The software supports two connection methods, namely `wired` connection and `wireless` connection. You can switch the connection mode to choose the way to establish a connection with the robot.

1.In the wired connection mode, the software automatically scans all available serial ports and remembers the last successful port number.

2.In the wireless connection mode, enter the IP address displayed on the small screen of the robotic arm for login.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/launch-2.png" />

When the toggle button is clicked, a secondary pop-up window will appear. Inside the pop-up window, there are specific operation methods. Please read them carefully and follow the instructions. Only after clicking the confirm button can the switch be made. 

If the current connection is wired, clicking this button will display a confirmation pop-up window for wireless connection. Clicking the `Confirm` button will switch to the wireless connection mode.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/launch-3.png" />


If the current connection is wireless, clicking this button will pop up a confirmation window for wired connection. Clicking the `Confirm` button will switch to the wired connection mode.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/launch-4.png" />

> Among them, the wireless connection only supports `IPV4` connection. Before logging in, a real-time check of the IP format will be conducted. If the check fails, a reminder message will be displayed. Only when the check is successful can the login function be used normally.

## 5 Login Module

### Wired connection login

**Notice:** Wired connection must ensure that the robotic arm is connected to the computer via a USB cable.

The automatic scanning system scans all available serial port devices. The port numbers scanned are arranged in ascending order. It supports a memory function. When the page is reloaded, the default selection is the port number that the user successfully used last time. Select the correct serial port and click the login button to log in and enter the main page of the software.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/launch-8.png" />

If multiple serial ports cannot be identified as the login serial port, for example with the Windows operating system, you can open the Device Manager in the settings panel -> Ports, and it will display all available serial port devices.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/launch-10.png" />

If the serial port cannot be detected, please ensure that the [serial port driver](./5.3.1-firstUse.md#preparation) has been downloaded. If it still cannot be detected after downloading, you can refer to [Q&A](./5.3.8-Q&A.md).

### Wireless Connection Login

**Notice:** Wireless connection must ensure that the robotic arm isconnected to the same network as the current computer.

Verify the input of the IP address. Only valid IPv4 addresses are supported. The specific login IP can be viewed through the Connection page or the WLAN page on the minirobot.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/launch-9.png" />

After confirming that the login information is correct, click the `Log in` button to proceed with the login process. Once the software successfully establishes communication with the robot, you can enter the main page of the software and use all the functional modules within it.

<img width = "1200" align = "center" src="../../../resources/C-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/home-1.png" />
