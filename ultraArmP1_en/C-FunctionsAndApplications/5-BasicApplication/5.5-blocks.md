# ultraArmP1 Block Description

This document lists the robotic arm blocks in the `ultraArmP1` toolbox. Value ranges are based on the current frontend defaults. Joint and coordinate limits may change with device configuration.

## Movement

### Trajectory

#### `move_to_trajectory`

Block: Play drag teach trajectory file

Function: Select and play a saved drag teach trajectory.

Parameters: Trajectory file: select from the current trajectory list.

### Waypoint

#### `move_to_point`

Block: Move to waypoint

Function: Move the robotic arm to the selected waypoint with the specified motion mode and speed.

Parameters: Waypoint: select from the current waypoint list; Mode: Joint motion, Linear motion; Speed: 1–100.

### Angle & Coord

#### `get_angles_info`

Block: Get the current angle of the robotic arm

Function: Read the current joint angles of the robotic arm.

Parameters: None.

#### `set_angle`

Block: Set joint angle

Function: Move the specified joint to the target angle at the set speed.

Parameters: Joint: 1–4; Angle: Joint 1 -165°–165°, Joint 2 -18°–85°, Joint 3 89°–200°, Joint 4 -179°–179°; Speed: 1–100.

#### `set_angles`

Block: Set all joint angles

Function: Move all four joints to their target angles at the set speed. Supports quick fill of the current angles.

Parameters: Joint 1 angle: -165°–165°; Joint 2 angle: -18°–85°; Joint 3 angle: 89°–200°; Joint 4 angle: -179°–179°; Speed: 1–100.

#### `get_coords_info`

Block: Get the current coordinates of the robotic arm

Function: Read the current X, Y, Z, and R coordinates of the robotic arm.

Parameters: None.

#### `set_coords_max_speed`

Block: Set coordinates at maximum speed

Function: Move the robotic arm to the specified coordinates at maximum speed. Supports quick fill of the current coordinates.

Parameters: X: -350–362.43; Y: -362.43–362.43; Z: -186.265–93.44; R: -180°–180°.

#### `set_coords`

Block: Set coordinates

Function: Move the robotic arm to the specified X, Y, Z, and R coordinates at the set speed. Supports quick fill of the current coordinates.

Parameters: X: -350–362.43; Y: -362.43–362.43; Z: -186.265–93.44; R: -180°–180°; Speed: 1–100.

#### `set_coord`

Block: Set a single coordinate

Function: Move the specified coordinate axis to the target value at the set speed.

Parameters: Coordinate axis: X, Y, Z, R; Target value: X -350–362.43, Y -362.43–362.43, Z -186.265–93.44, R -180°–180°; Speed: 1–100.

#### `stop`

Block: Stop

Function: Stop the current motion of the robotic arm.

Parameters: None.

### JOG Control

#### `set_jog_angle`

Block: Set joint JOG angle motion

Function: Continuously jog the specified joint in the selected direction at the set speed.

Parameters: Joint: 1–4; Direction: Positive jog, Negative jog; Speed: 1–100.

#### `set_jog_coord`

Block: Set coordinate JOG motion

Function: Continuously jog the specified coordinate axis in the selected direction at the set speed.

Parameters: Coordinate axis: X, Y, Z, R; Direction: Positive jog, Negative jog; Speed: 1–100.

#### `jog_increment_coord`

Block: Set coordinate JOG increment motion

Function: Move the specified coordinate axis by the set increment at the set speed.

Parameters: Coordinate axis: X, Y, Z, R; Increment: X -350–362.43, Y -362.43–362.43, Z -186.265–93.44, R -180°–180°; Speed: 1–100.

#### `jog_increment_angle`

Block: Set joint JOG angle increment motion

Function: Move the specified joint by the set angle increment at the set speed.

Parameters: Joint: 1–4; Increment: Joint 1 -165°–165°, Joint 2 -18°–85°, Joint 3 89°–200°, Joint 4 -179°–179°; Speed: 1–100.

### Operation assistance

#### `set_joint_release`

Block: Release joint

Function: Disable the motor of the specified joint so it can be moved manually.

Parameters: Joint: 1–4.

#### `set_joint_enable`

Block: Lock joint

Function: Enable the motor of the specified joint to keep it locked.

Parameters: Joint: 1–4.

#### `set_pwm`

Block: Set PWM control

Function: Set the PWM control level of the robotic arm.

Parameters: PWM control value: 0–5.

#### `set_zero_calibration`

Block: Set joint zero calibration

Function: Set the current position of the specified joint as the zero position.

Parameters: Joint: All joints, Joint 1, Joint 2, Joint 3, Joint 4.

#### `get_zero_calibration_state`

Block: Get zero calibration state

Function: Read the zero calibration state of each joint.

Parameters: None.

#### `get_motor_enable_status`

Block: Get motor enable status

Function: Read whether the robotic arm motors are currently enabled.

Parameters: None.

## End tool

### Gripper

#### `set_gripper_angle`

Block: Set gripper angle

Function: Move the gripper to the specified angle at the set speed.

Parameters: Angle: 1–100; Speed: 1–100.

#### `get_gripper_angle`

Block: Get gripper angle

Function: Read the current gripper angle.

Parameters: None.

#### `get_gripper_run_status`

Block: Get gripper run status

Function: Read the current running status of the gripper.

Parameters: None.

#### `set_gripper_enable_status`

Block: Set gripper enable status

Function: Set the enable status of the gripper motor.

Parameters: Status: Disabled, Enabled.

#### `set_gripper_parameter`

Block: Set gripper parameter

Function: Write a gripper configuration value to the specified parameter address.

Parameters: Address: 1–69; Parameter value: 1–65535.

#### `get_gripper_parameter`

Block: Get gripper parameter

Function: Read the gripper parameter value at the specified address.

Parameters: Address: 1–69.

#### `set_gripper_zero`

Block: Set the gripper to zero position

Function: Set the current gripper position as the zero position.

Parameters: None.

### Pump

#### `set_pump_state`

Block: Set pump state

Function: Set the working state of the pump.

Parameters: State: Open, Release, Close.

### Laser

#### `open_laser`

Block: Set PWM laser mode

Function: Enable or disable PWM laser mode.

Parameters: Mode: Open, Close.

#### `set_pwm_laser`

Block: Set PWM laser

Function: Set the PWM output value in laser mode.

Parameters: PWM value: 0–255.

#### `set_pwm_custom_mode`

Block: Set PWM custom mode

Function: Enable or disable PWM custom output mode.

Parameters: Mode: Open, Close.

#### `set_pwm_custom`

Block: Set PWM custom

Function: Set the PWM output value in custom mode.

Parameters: PWM value: 0–255.

#### `get_pwm_status`

Block: Get PWM output status

Function: Read the current PWM output status.

Parameters: None.

#### `laser_engraving_pause_time`

Block: Laser engraving pause time

Function: Set the pause time during laser engraving.

Parameters: Pause time: 0–1000.

## Status

### System Information

#### `set_button_enable`

Block: Enable free move mode

Function: Enable free move mode controlled by the end button.

Parameters: None.

#### `set_button_disable`

Block: Disable free move mode

Function: Disable free move mode controlled by the end button.

Parameters: None.

#### `get_end_button_state`

Block: Get end button state

Function: Read the current state of the robotic arm end button.

Parameters: None.

#### `forced_reset_zero`

Block: Forced reset zero

Function: Force the robotic arm to return to the zero position.

Parameters: None.

#### `set_conveyor_control`

Block: Set conveyor belt control

Function: Set the conveyor belt on/off state, direction, speed, and travel distance.

Parameters: Status: Open, Close; Direction: Forward, Backward; Speed: 1–125; Conveyor distance: 1–1200.

#### `set_conveyor_stop`

Block: Set conveyor belt stop movement

Function: Stop the conveyor belt motion.

Parameters: None.

#### `set_i2c_data`

Block: Set I2C data

Function: Read or write I2C data at the specified address.

Parameters: State: Read, Write; Address: 0–255; Data length: 0–64; Data value: 0–255.

#### `play_gcode_file`

Block: Play scene application G-code file

Function: Play the specified scene application G-code trajectory file.

Parameters: File name or file path: string.

#### `collision_unlock`

Block: Unlock after collision detection

Function: Unlock the robotic arm after a collision protection trigger.

Parameters: None.

#### `get_limit_switch_state`

Block: Get limit switch state

Function: Read the current state of the limit switch.

Parameters: None.

#### `set_color`

Block: Set color board color

Function: Set the color board color using RGB values.

Parameters: R: 0–255; G: 0–255; B: 0–255.

### IO Control

#### `get_base_io_state`

Block: Get the status of the bottom IO pin

Function: Read the current state of the specified base IO pin.

Parameters: Pin: 1–10.

#### `set_base_io_output`

Block: Set basic IO

Function: Set the input/output mode and level signal of the specified base IO pin.

Parameters: Pin: 1–10; Status: Input, Output; Signal: Low level, High level.

#### `get_end_io_state`

Block: Get the status of the end IO pin

Function: Read the current state of the specified end IO pin.

Parameters: Pin: 1–4.

#### `set_digital_io_output`

Block: Set end IO output

Function: Set the output level of the specified end IO pin.

Parameters: Pin: 1–4; Signal: Low level, High level.

#### `get_all_base_io_states`

Block: Get all base IO states

Function: Read the states of all base IO pins.

Parameters: None.

#### `get_all_end_io_states`

Block: Get all end IO states

Function: Read the states of all end IO pins.

Parameters: None.

### Operating Status

#### `get_error_information`

Block: Get error information

Function: Read the current error information of the robotic arm.

Parameters: None.

#### `get_queue_size`

Block: Get queue size

Function: Read the size of the current pending command queue.

Parameters: None.

#### `get_run_status`

Block: Get running status

Function: Read the current running status of the robotic arm.

Parameters: None.

#### `clear_error_status`

Block: Clear error status

Function: Clear the current error status of the robotic arm.

Parameters: None.
